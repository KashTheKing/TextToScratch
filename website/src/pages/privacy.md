# Privacy Policy

*Last updated: October 2, 2026*

TextToScratch (the browser extension, web editor and compiler) **does not collect, store or share any personal data.**

- All code is compiled locally in your browser. Your code and projects are never sent to TextToScratch or any third party.
- Your TypeScript source is saved inside your Scratch project (as project comments), on Scratch's or TurboWarp's servers, only when *you* save the project there. That is governed by those sites' own privacy policies.
- The extension uses no analytics, tracking, cookies or remote code. It only runs on `scratch.mit.edu/projects/*` and `turbowarp.org` pages to add the code editor.
- This website is hosted on GitHub Pages, which may keep standard server logs (see GitHub's privacy statement).

Questions? See [Support](/support).
