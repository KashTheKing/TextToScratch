## Description
TextToScratch adds a "Text Code" button to the Scratch editor (scratch.mit.edu and TurboWarp). It opens a code editor where you write your project in TypeScript, with full type checking and autocomplete, and compiles it into real Scratch blocks.

• One file per sprite; image and sound folders become costumes and sounds
• Type errors for typos in sprite, costume, sound and backdrop names
• Built-in game engine: input, physics, collision, camera, animation, 3D, multiplayer (cloud variables), classes
• Your code is saved inside the project, so you can keep editing it later
• Everything runs locally in your browser
